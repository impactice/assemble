## 6.10.1 단답형 (Short Answer)

### 1. 실행 후 BX 값은?

```asm
mov bx,0FFFFh
and bx,6Bh
```

**BX = 006Bh**

FFFFh는 모든 비트가 1이므로, AND 하면 상대편 비트가 그대로 남습니다.

```
  1111 1111 1111 1111   (FFFFh)
& 0000 0000 0110 1011   (006Bh)
  ───────────────────
  0000 0000 0110 1011   (006Bh)
```

> 성질: **X AND 1 = X**, **X AND 0 = 0**

---

### 2. 실행 후 BX 값은?

```asm
mov bx,91BAh
and bx,92h
```

**BX = 0092h**

```
  1001 0001 1011 1010   (91BAh)
& 0000 0000 1001 0010   (0092h)
  ───────────────────
  0000 0000 1001 0010   (0092h)
```

하위 바이트만 보면 BAh AND 92h 입니다.
```
  1011 1010   (BAh)
& 1001 0010   (92h)
  ─────────
  1001 0010   (92h)
```
상위 바이트는 91h AND 00h = 00h 입니다.

---

### 3. 실행 후 BX 값은?

```asm
mov bx,0649Bh
or  bx,3Ah
```

**BX = 64BBh**

```
  0110 0100 1001 1011   (649Bh)
| 0000 0000 0011 1010   (003Ah)
  ───────────────────
  0110 0100 1011 1011   (64BBh)
```

하위 바이트: 9Bh OR 3Ah
```
  1001 1011   (9Bh)
| 0011 1010   (3Ah)
  ─────────
  1011 1011   (BBh)
```

> 성질: **X OR 0 = X**, **X OR 1 = 1**

---

### 4. 실행 후 BX 값은?

```asm
mov bx,029D6h
xor bx,8181h
```

**BX = A357h**

```
  0010 1001 1101 0110   (29D6h)
^ 1000 0001 1000 0001   (8181h)
  ───────────────────
  1010 0011 0101 0111   (A357h)
```

자리별로 보면, 2h^8h = Ah, 9h^1h = 8h… 가 아니라 16진수 자리마다 따로 계산해야 합니다.
- 2 XOR 8 = 0010 ^ 1000 = 1010 = **A**
- 9 XOR 1 = 1001 ^ 0001 = 1000 = **8**… 

정확히 하면 니블 단위로 이렇습니다.

| 니블 | 29D6h | 8181h | XOR |
|---|---|---|---|
| 1 | 2 (0010) | 8 (1000) | A (1010) |
| 2 | 9 (1001) | 1 (0001) | 8 (1000) |
| 3 | D (1101) | 8 (1000) | 5 (0101) |
| 4 | 6 (0110) | 1 (0001) | 7 (0111) |

**BX = A857h**

> 성질: **같으면 0, 다르면 1**

---

### 5. 실행 후 EBX 값은?

```asm
mov ebx,0AFAF649Bh
or  ebx,3A219604h
```

**EBX = BFBFF69Fh**

니블 단위로 OR 합니다.

| | AFAF649Bh | 3A219604h | OR |
|---|---|---|---|
| | A (1010) | 3 (0011) | B (1011) |
| | F (1111) | A (1010) | F (1111) |
| | A (1010) | 2 (0010) | A (1010) |
| | F (1111) | 1 (0001) | F (1111) |
| | 6 (0110) | 9 (1001) | F (1111) |
| | 4 (0100) | 6 (0110) | 6 (0110) |
| | 9 (1001) | 0 (0000) | 9 (1001) |
| | B (1011) | 4 (0100) | F (1111) |

**EBX = BFAFF69Fh**

### 6. 실행 후 RBX 값은?

```asm
mov rbx,0AFAF649Bh
xor rbx,0FFFFFFFFh
```

**RBX = 00000000505 09B64h**

정확히 계산하면 이렇습니다. 먼저 `mov rbx,0AFAF649Bh` 는 32비트 상수이므로 **상위 32비트가 0으로 지워집니다**. RBX = 00000000AFAF649Bh 입니다.

FFFFFFFFh와 XOR 하면 하위 32비트가 **전부 반전**됩니다.

| 니블 | A | F | A | F | 6 | 4 | 9 | B |
|---|---|---|---|---|---|---|---|---|
| 반전 | 5 | 0 | 5 | 0 | 9 | B | 6 | 4 |

**RBX = 0000000050509B64h**

> 성질: **X XOR 1 = NOT X** — 모든 비트를 1과 XOR 하면 1의 보수가 됩니다.

### 7. 각 명령어 실행 후 AL의 2진 값은?

```asm
mov al,01101111b
and al,00101101b        ; (a)

mov al,6Dh
and al,4Ah              ; (b)

mov al,00001111b
or  al,61h              ; (c)

mov al,94h
xor al,37h              ; (d)
```

**(a) AL = 00101101b**
```
  0110 1111
& 0010 1101
  ─────────
  0010 1101
```

**(b) AL = 01001000b (48h)**
6Dh = 0110 1101, 4Ah = 0100 1010
```
  0110 1101
& 0100 1010
  ─────────
  0100 1000
```

**(c) AL = 01101111b (6Fh)**
61h = 0110 0001
```
  0000 1111
| 0110 0001
  ─────────
  0110 1111
```

**(d) AL = 10100011b (A3h)**
94h = 1001 0100, 37h = 0011 0111
```
  1001 0100
^ 0011 0111
  ─────────
  1010 0011
```

### 8. 각 명령어 실행 후 AL의 16진 값은?

```asm
mov al,7Ah
not al                  ; (a)

mov al,3Dh
and al,74h              ; (b)

mov al,9Bh
or  al,35h              ; (c)

mov al,72h
xor al,0DCh             ; (d)
```

**(a) AL = 85h**
7Ah = 0111 1010 → 반전 → 1000 0101 = 85h

**(b) AL = 34h**
3Dh = 0011 1101, 74h = 0111 0100
```
  0011 1101
& 0111 0100
  ─────────
  0011 0100   = 34h
```

**(c) AL = BFh**
9Bh = 1001 1011, 35h = 0011 0101
```
  1001 1011
| 0011 0101
  ─────────
  1011 1111   = BFh
```

**(d) AL = AEh**
72h = 0111 0010, DCh = 1101 1100
```
  0111 0010
^ 1101 1100
  ─────────
  1010 1110   = AEh
```

### 9. 각 지점에서 Carry, Zero, Sign 플래그 값은?

```asm
mov al,00001111b
test al,00000010b       ; (a)

mov al,00000110b
cmp al,00000101b        ; (b)

mov al,00000101b
cmp al,00000111b        ; (c)
```

**(a) CF = 0, ZF = 0, SF = 0**

TEST는 AND를 수행하되 결과를 저장하지 않습니다.
```
  0000 1111
& 0000 0010
  ─────────
  0000 0010   → 0이 아님
```
결과가 0이 아니므로 ZF = 0, MSB가 0이라 SF = 0 입니다. **TEST는 CF와 OF를 항상 0으로 지웁니다.**

**(b) CF = 0, ZF = 0, SF = 0**

CMP는 암묵적 뺄셈입니다. 6 − 5 = 1 입니다.
결과가 양수이고 0이 아니며 빌림도 없습니다.

**(c) CF = 1, ZF = 0, SF = 1**

5 − 7 = −2 입니다.
- 작은 수에서 큰 수를 뺐으므로 **CF = 1**
- 결과(FEh)의 MSB가 1이라 **SF = 1**
- 0이 아니므로 ZF = 0

### 10. ECX 내용을 기준으로 분기하는 조건 점프 명령어는?

**JECXZ** (ECX = 0 이면 점프)

64비트에서는 **JRCXZ** 입니다(RCX = 0 이면 점프).

> 플래그가 아니라 **레지스터 값**을 직접 보는 유일한 조건 점프입니다.

---

### 11. JA와 JNBE는 Zero와 Carry 플래그의 어떤 조합에서 동작하는가?

**CF = 0 이고 ZF = 0 일 때** 점프합니다.

- JA (jump if above) — 부호 없는 비교에서 좌 > 우
- JNBE (jump if not below or equal) — "작거나 같지 않다" = "크다"

두 명령어는 **같은 기계어 코드**입니다. 이름만 다릅니다.

| 상태 | 의미 |
|---|---|
| CF = 1 | 좌 < 우 (below) |
| ZF = 1 | 좌 = 우 (equal) |
| 둘 다 0 | **좌 > 우 (above)** → 점프 |

---

### 12. 실행 후 EDX 값은?

```asm
    mov edx,1
    mov eax,7FFFh
    cmp eax,8000h
    jl  L1
    mov edx,0
L1:
```

**EDX = 1**

JL은 **부호 있는** 비교입니다.
- 7FFFh = +32767
- 8000h = +32768 (32비트 값이므로 양수입니다. 16비트였다면 −32768)

여기서 EAX는 32비트 레지스터이므로 00007FFFh와 00008000h를 비교합니다. 둘 다 양수이고 32767 < 32768 이므로 **점프합니다**. `mov edx,0` 을 건너뛰어 EDX = 1 이 유지됩니다.

---

### 13. 실행 후 EDX 값은?

```asm
    mov edx,1
    mov eax,7FFFh
    cmp eax,8000h
    jb  L1
    mov edx,0
L1:
```

**EDX = 1**

JB는 **부호 없는** 비교입니다. 32767 < 32768 이므로 CF = 1 이 되어 점프합니다. 이 경우 두 값이 모두 양수 범위라 JL과 결과가 같습니다.

---

### 14. 실행 후 EDX 값은?

```asm
    mov edx,1
    mov eax,7FFFh
    cmp eax,0FFFF8000h
    jl  L2
    mov edx,0
L2:
```

**EDX = 0**

- 7FFFh = +32767 (양수)
- FFFF8000h = **−32768** (MSB가 1이므로 음수)

JL은 부호 있는 비교이므로 +32767 < −32768 은 **거짓**입니다. 점프하지 않고 `mov edx,0` 이 실행됩니다.

> 만약 JB(부호 없는)였다면 7FFFh < FFFF8000h 가 참이라 점프했을 겁니다. **같은 데이터라도 부호 해석에 따라 결과가 뒤집히는** 전형적인 예입니다.

---

### 15. (참/거짓) 다음 코드는 Target으로 점프한다.

```asm
mov eax,-30
cmp eax,-50
jg  Target
```

**참.**

JG는 부호 있는 비교입니다. −30 > −50 이므로 점프합니다.

> 주의: 부호 없는 비교(JA)였다면 −30 = FFFFFFE2h, −50 = FFFFFFCEh 이고 E2h > CEh 이므로 역시 점프했을 겁니다. 이 경우는 우연히 같습니다.

---

### 16. (참/거짓) 다음 코드는 Target으로 점프한다.

```asm
mov eax,-42
cmp eax,26
ja  Target
```

**참.**

JA는 **부호 없는** 비교입니다.
- −42 = FFFFFFD6h (부호 없이 읽으면 약 42억)
- 26 = 0000001Ah

부호 없는 값으로는 FFFFFFD6h가 훨씬 크므로 점프합니다.

> 부호 있는 비교(JG)였다면 −42 > 26 이 거짓이라 점프하지 않습니다. **A/B와 G/L을 구분해야 하는 이유**를 보여 주는 문제입니다.

---

### 17. 실행 후 RBX 값은?

```asm
mov rbx,0FFFFFFFFFFFFFFFFh
and rbx,80h
```

**RBX = 0000000000000080h**

모든 비트가 1인 값과 80h를 AND 하면 80h만 남습니다.

> 64비트 상수를 직접 쓸 수 있고, AND의 피연산자 80h는 8비트지만 64비트로 부호 확장 없이 처리됩니다.

---

### 18. 실행 후 RBX 값은?

```asm
mov rbx,0FFFFFFFFFFFFFFFFh
and rbx,808080h
```

**RBX = 0000000000808080h**

---

### 19. 실행 후 RBX 값은?

```asm
mov rbx,0FFFFFFFFFFFFFFFFh
and rbx,80808080h
```

**RBX = FFFFFFFF80808080h**

⭐ **여기가 함정입니다.** 앞의 17, 18번과 결과 형태가 다릅니다.

80808080h는 **32비트 상수**입니다. 64비트 모드에서 32비트 즉시값을 쓰면 상위 32비트가 어떻게 되는지가 핵심인데, AND 연산에서는 **하위 32비트만 영향을 받고 상위 32비트는 그대로 남습니다**.

| 상수 크기 | 결과 |
|---|---|
| 80h (8비트) | 상위가 0으로 → 0000...0080h |
| 808080h (24비트) | 상위가 0으로 → 0000...808080h |
| **80808080h (32비트)** | **상위 32비트 유지** → FFFFFFFF80808080h |

> 교재 6.2.10절에서 "32비트 피연산자는 특별한 경우로 따로 봐야 한다"고 강조하는 부분입니다.

## 6.10.2 알고리즘 연습 (Algorithm Workbench)

### 1. AL의 ASCII 숫자를 2진 값으로 바꾸는 명령어 하나

```asm
and al,0Fh              ; 또는 and al,00001111b
```

ASCII 숫자는 30h~39h 입니다. 상위 니블(3)을 지우면 0~9가 남습니다.

| 문자 | ASCII | AND 0Fh 후 |
|---|---|---|
| '0' | 30h | 00h |
| '5' | 35h | 05h |
| '9' | 39h | 09h |

이미 2진 값(00h~09h)이면 상위 니블이 0이라 AND를 해도 변하지 않습니다.

> `sub al,30h` 로도 되지만, 이미 2진 값인 경우 음수가 되어 버립니다. AND가 더 안전합니다.

---

### 2. 32비트 메모리 피연산자의 패리티 계산

32비트를 4바이트 B0~B3 으로 나누고 전부 XOR 합니다.

```asm
.data
dwordVal DWORD 12345678h

.code
    mov eax,dwordVal
    xor al,ah               ; B0 XOR B1
    shr eax,16              ; 상위 워드를 하위로
    xor al,ah               ; (B2 XOR B3)
    ; 여기서 문제: 이전 결과가 날아감
```

제대로 하려면 이렇습니다.

```asm
    mov eax,dwordVal
    mov ebx,eax
    shr ebx,16              ; EBX 하위 = B3 B2
    xor eax,ebx             ; AL = B0^B2, AH = B1^B3
    xor al,ah               ; AL = B0^B1^B2^B3
    ; 이 시점의 PF가 전체 패리티
    jp  EvenParity
    jnp OddParity
```

**원리**: 패리티는 1 비트 개수의 홀짝이므로, XOR로 접어 나가도 홀짝은 보존됩니다.

---

### 3. SetX에는 있고 SetY에는 없는 원소를 EAX에 생성

**차집합 (SetX − SetY)** 입니다.

```asm
mov eax,SetY
not eax                 ; SetY의 여집합
and eax,SetX            ; SetX ∩ (SetY의 여집합)
```

집합 연산으로 쓰면 **X ∩ Y' = X − Y** 입니다.

| 집합 연산 | 명령어 |
|---|---|
| 교집합 | AND |
| 합집합 | OR |
| 여집합 | NOT |
| 차집합 | NOT + AND |

---

### 4. DX ≤ CX 이면 L1으로 점프 (부호 없는 정수)

```asm
cmp dx,cx
jbe L1                  ; below or equal (부호 없음)
```

> 부호 없는 비교이므로 **JBE**를 씁니다. JLE는 부호 있는 비교입니다.

---

### 5. AX > CX 이면 L2로 점프 (부호 있는 정수)

```asm
cmp ax,cx
jg  L2                  ; greater (부호 있음)
```

> 부호 있는 비교이므로 **JG**를 씁니다.

---

### 6. AL의 비트 0과 1을 지운 뒤, 결과가 0이면 L3으로 아니면 L4로 점프

```asm
and al,11111100b        ; 비트 0, 1 지우기
jz  L3                  ; 결과가 0이면
jmp L4                  ; 아니면
```

**핵심**
- 지우고 싶은 비트는 **0으로**, 남기고 싶은 비트는 **1로** 두고 AND 합니다.
- AND가 Zero 플래그를 설정하므로 바로 JZ를 쓸 수 있습니다.

> `and al,0FCh` 로 써도 같습니다.

---

### 7. 단락 평가로 구현: `if (val1 > ecx) AND (ecx > edx) then X=1 else X=2`

```asm
    mov eax,val1
    cmp eax,ecx             ; 첫 조건
    jbe L2                  ; 거짓이면 바로 else로
    cmp ecx,edx             ; 둘째 조건
    jbe L2                  ; 거짓이면 else로
L1: mov X,1                 ; 둘 다 참
    jmp L3
L2: mov X,2                 ; 하나라도 거짓
L3:
```

**AND 복합 조건의 규칙** ⭐
- 각 조건을 **반대로 뒤집어** 거짓일 때 else로 보냅니다
- 모든 조건을 통과해야 then 블록에 도달합니다
- 첫 조건이 거짓이면 둘째를 **평가하지 않습니다** (단락 평가)

---

### 8. 단락 평가로 구현: `if (ebx > ecx) OR (ebx > val1) then X=1 else X=2`

```asm
    cmp ebx,ecx             ; 첫 조건
    ja  L1                  ; 참이면 바로 then으로
    cmp ebx,val1            ; 둘째 조건
    jbe L2                  ; 둘 다 거짓이면 else로
L1: mov X,1                 ; 하나라도 참
    jmp L3
L2: mov X,2                 ; 둘 다 거짓
L3:
```

**OR 복합 조건의 규칙** ⭐
- 조건을 **그대로** 두고 참일 때 then으로 보냅니다
- **마지막 조건만** 뒤집어 거짓일 때 else로 보냅니다
- 첫 조건이 참이면 둘째를 평가하지 않습니다

---

### 9. 구현: `if (ebx > ecx AND ebx > edx) OR (edx > eax) then X=1 else X=2`

```asm
    ; 첫 번째 괄호: AND 조건
    cmp ebx,ecx
    jbe L1                  ; 첫 AND 조건 실패 → 둘째 OR 항으로
    cmp ebx,edx
    ja  L2                  ; AND 둘 다 참 → then으로

L1: ; 두 번째 OR 항
    cmp edx,eax
    jbe L3                  ; 이것도 거짓 → else로

L2: mov X,1                 ; 참
    jmp L4
L3: mov X,2                 ; 거짓
L4:
```

**구조 분석**
```
(A AND B) OR C
```
- A가 거짓이면 AND 전체가 거짓 → C를 평가하러 L1으로
- A가 참이고 B도 참이면 → 전체 참, L2로
- A가 참인데 B가 거짓이면 → AND 거짓, C를 평가하러 L1으로… 

> 위 코드에서 `cmp ebx,edx` 가 거짓이면 자연스럽게 L1 다음 줄로 흐르지 않고 L1을 지나칩니다. 정확히 하려면 이렇게 고칩니다.

```asm
    cmp ebx,ecx
    jbe L1
    cmp ebx,edx
    ja  L2                  ; A AND B 참
L1: cmp edx,eax             ; C 평가
    jbe L3
L2: mov X,1
    jmp L4
L3: mov X,2
L4:
```
`ja L2` 가 실패하면 바로 다음 줄인 L1으로 흘러 들어가므로 의도대로 동작합니다.

### 10. 구현 (A, B, N은 32비트 부호 있는 정수)

```
while N > 0
    if N != 3 AND (N < A OR N > B)
        N = N - 2
    else
        N = N - 1
end while
```

```asm
while_top:
    cmp N,0
    jle while_end           ; N <= 0 이면 루프 종료 (부호 있음)

    ; if 조건 평가
    mov eax,N

    cmp eax,3
    je  else_part           ; N == 3 이면 AND 실패 → else

    ; (N < A OR N > B) 평가
    cmp eax,A
    jl  then_part           ; N < A 이면 참 → then
    cmp eax,B
    jg  then_part           ; N > B 이면 참 → then
    jmp else_part           ; 둘 다 거짓 → else

then_part:
    sub N,2
    jmp while_top

else_part:
    sub N,1
    jmp while_top

while_end:
```

**분석 순서**
1. 바깥 WHILE 조건을 뒤집어(`jle`) 탈출합니다
2. AND의 첫 항 `N != 3` 을 뒤집어(`je`) else로 보냅니다
3. 괄호 안 OR는 참일 때 then으로 보냅니다
4. OR의 마지막 항도 거짓이면 else로 보냅니다

> 모든 비교에 **부호 있는 점프(JLE, JL, JG)** 를 썼습니다. 문제에서 부호 있는 정수라고 했기 때문입니다.

### 1. 배열 채우기 ★★

**문제**: 배열을 j~k 범위의 난수 N개로 채우는 프로시저를 작성하시오. 배열 포인터, N, j, k를 전달하고 레지스터를 보존합니다.

```asm
INCLUDE Irvine32.inc

ARRAY_SIZE = 20

.data
array DWORD ARRAY_SIZE DUP(?)

.code
main PROC
    call Randomize

    ; 첫 번째 호출: 10 ~ 50
    mov esi,OFFSET array
    mov ecx,ARRAY_SIZE
    mov ebx,10                  ; 하한 j
    mov edx,50                  ; 상한 k
    call FillArray
    call ShowArray

    ; 두 번째 호출: -100 ~ -50
    mov esi,OFFSET array
    mov ecx,ARRAY_SIZE
    mov ebx,-100
    mov edx,-50
    call FillArray
    call ShowArray

    exit
main ENDP

;---------------------------------------------------
; FillArray
; 배열을 j ~ k 범위의 난수로 채운다.
; Receives: ESI = 배열 주소, ECX = 개수,
;           EBX = 하한(j), EDX = 상한(k)
; Returns:  nothing
;---------------------------------------------------
FillArray PROC USES eax ebx ecx edx esi
    cmp ecx,0
    je  done

    mov eax,edx
    sub eax,ebx
    inc eax                     ; 범위 폭 = k - j + 1
    mov edx,eax                 ; 폭을 EDX에 보관

L1:
    push ecx                    ; 카운터 보존
    mov eax,edx                 ; 범위 폭
    call RandomRange            ; 0 ~ 폭-1
    add eax,ebx                 ; j만큼 이동
    mov [esi],eax
    add esi,4
    pop ecx
    loop L1

done:
    ret
FillArray ENDP

ShowArray PROC USES eax ecx esi
    mov esi,OFFSET array
    mov ecx,ARRAY_SIZE
L1: mov eax,[esi]
    call WriteInt
    mov al,' '
    call WriteChar
    add esi,4
    loop L1
    call Crlf
    ret
ShowArray ENDP
END main
```

**핵심**
- 범위 폭은 `k − j + 1` 입니다. **inclusive**이므로 +1을 잊지 마세요.
- `RandomRange`가 EAX를 쓰므로 ECX를 PUSH/POP으로 보호합니다.
- `USES`로 레지스터를 보존합니다.

### 2. 범위 내 원소 합계 ★

**문제**: 배열에서 j~k 범위에 속하는 원소들의 합을 구해 EAX로 반환하시오.

```asm
INCLUDE Irvine32.inc

.data
array DWORD 10,-5,30,45,-20,60,15,80
count DWORD LENGTHOF array
sum   DWORD ?

.code
main PROC
    ; 0 ~ 50 범위의 합
    mov esi,OFFSET array
    mov ecx,count
    mov ebx,0                   ; j
    mov edx,50                  ; k
    call SumInRange
    call WriteInt
    call Crlf

    ; -20 ~ 20 범위의 합
    mov esi,OFFSET array
    mov ecx,count
    mov ebx,-20
    mov edx,20
    call SumInRange
    call WriteInt
    call Crlf

    exit
main ENDP

;---------------------------------------------------
; SumInRange
; j <= 원소 <= k 인 원소들의 합을 구한다.
; Receives: ESI = 배열, ECX = 개수, EBX = j, EDX = k
; Returns:  EAX = 합계
;---------------------------------------------------
SumInRange PROC USES ebx ecx edx esi edi
    mov edi,0                   ; 누적 합
    cmp ecx,0
    je  done

L1:
    mov eax,[esi]

    cmp eax,ebx
    jl  skip                    ; 원소 < j 이면 건너뜀 (부호 있음)
    cmp eax,edx
    jg  skip                    ; 원소 > k 이면 건너뜀

    add edi,eax                 ; 범위 안이면 누적

skip:
    add esi,4
    loop L1

done:
    mov eax,edi                 ; 결과를 EAX로
    ret
SumInRange ENDP
END main
```

**핵심**
- 범위 검사는 **AND 조건**입니다. 둘 다 통과해야 더합니다.
- 조건을 뒤집어 `skip`으로 보내는 패턴을 씁니다.
- 부호 있는 배열이므로 **JL, JG**를 씁니다.
- 반환값 EAX는 USES에 넣지 않고, 누적은 EDI에 하다가 마지막에 옮깁니다.

### 3. 시험 점수 평가 ★★

**문제**: 0~100 점수를 받아 학점(A~F)을 AL로 반환하는 CalcGrade 프로시저를 작성하시오.

| 점수 | 학점 |
|---|---|
| 90~100 | A |
| 80~89 | B |
| 70~79 | C |
| 60~69 | D |
| 0~59 | F |

```asm
INCLUDE Irvine32.inc

.data
scoreMsg BYTE "Score: ",0
gradeMsg BYTE "  Grade: ",0

.code
main PROC
    call Randomize
    mov ecx,10                  ; 10개 테스트

L1:
    push ecx

    ; 50 ~ 100 사이 난수
    mov eax,51                  ; 폭 = 100 - 50 + 1
    call RandomRange
    add eax,50
    push eax                    ; 점수 보관

    mov edx,OFFSET scoreMsg
    call WriteString
    call WriteDec

    pop eax                     ; 점수 복원
    call CalcGrade              ; → AL

    push eax
    mov edx,OFFSET gradeMsg
    call WriteString
    pop eax
    call WriteChar
    call Crlf

    pop ecx
    loop L1

    exit
main ENDP

;---------------------------------------------------
; CalcGrade
; 점수를 학점으로 변환한다.
; Receives: EAX = 점수 (0~100)
; Returns:  AL = 학점 문자
;---------------------------------------------------
CalcGrade PROC
    cmp eax,90
    jae gradeA
    cmp eax,80
    jae gradeB
    cmp eax,70
    jae gradeC
    cmp eax,60
    jae gradeD

    mov al,'F'
    jmp done

gradeA: mov al,'A'
        jmp done
gradeB: mov al,'B'
        jmp done
gradeC: mov al,'C'
        jmp done
gradeD: mov al,'D'

done:
    ret
CalcGrade ENDP
END main
```

**핵심**
- **높은 점수부터** 검사해야 합니다. 낮은 쪽부터 하면 90점도 D에 걸립니다.
- 점수는 음수가 없으므로 부호 없는 **JAE**를 씁니다.
- 각 분기마다 `jmp done` 을 넣지 않으면 아래로 흘러 내려갑니다(fall-through).

> `.IF` 지시어를 쓰면 더 간단합니다.
> ```asm
> .IF eax >= 90
>     mov al,'A'
> .ELSEIF eax >= 80
>     mov al,'B'
> .ELSEIF eax >= 70
>     mov al,'C'
> .ELSEIF eax >= 60
>     mov al,'D'
> .ELSE
>     mov al,'F'
> .ENDIF
> ```

**문제**: 6.7.3절의 등록 예제를 CMP와 조건 점프로 다시 작성하고, 학점 수(credits) 범위 검사와 사용자 입력, 결과 메시지를 추가하시오.

INCLUDE Irvine32.inc

promptAvg   BYTE "Enter grade average (0-400): ",0

### 5. 불 계산기 (1) ★★★

**문제**: 32비트 정수용 간단한 불 계산기를 만드시오. 메뉴를 표시하고 선택에 따라 프로시저 이름을 표시합니다. **테이블 기반 선택**을 사용해야 합니다.

```asm
INCLUDE Irvine32.inc

.data
menu BYTE "Boolean Calculator",0dh,0ah
     BYTE "1. x AND y",0dh,0ah
     BYTE "2. x OR y",0dh,0ah
     BYTE "3. NOT x",0dh,0ah
     BYTE "4. x XOR y",0dh,0ah
     BYTE "5. Exit",0dh,0ah
     BYTE "Choice: ",0

msgAND BYTE "AND operation",0dh,0ah,0
msgOR  BYTE "OR operation",0dh,0ah,0
msgNOT BYTE "NOT operation",0dh,0ah,0
msgXOR BYTE "XOR operation",0dh,0ah,0
msgBad BYTE "Invalid choice",0dh,0ah,0

; 테이블: (선택값, 프로시저 주소) 쌍
CaseTable BYTE  '1'
          DWORD AND_op
EntrySize = ($ - CaseTable)
          BYTE  '2'
          DWORD OR_op
          BYTE  '3'
          DWORD NOT_op
          BYTE  '4'
          DWORD XOR_op
NumEntries = ($ - CaseTable) / EntrySize

.code
main PROC
menuLoop:
    call Clrscr
    mov edx,OFFSET menu
    call WriteString
    call ReadChar
    call WriteChar
    call Crlf

    cmp al,'5'
    je  quit

    ; 테이블 검색
    mov ebx,OFFSET CaseTable
    mov ecx,NumEntries

L1:
    cmp al,[ebx]                ; 선택값과 비교
    jne L2                      ; 다르면 다음 항목
    call NEAR PTR [ebx+1]       ; 일치하면 프로시저 호출
    jmp found

L2:
    add ebx,EntrySize
    loop L1

    ; 일치하는 항목 없음
    mov edx,OFFSET msgBad
    call WriteString

found:
    call WaitMsg
    jmp menuLoop

quit:
    exit
main ENDP

AND_op PROC
    mov edx,OFFSET msgAND
    call WriteString
    ret
AND_op ENDP

OR_op PROC
    mov edx,OFFSET msgOR
    call WriteString
    ret
OR_op ENDP

NOT_op PROC
    mov edx,OFFSET msgNOT
    call WriteString
    ret
NOT_op ENDP

XOR_op PROC
    mov edx,OFFSET msgXOR
    call WriteString
    ret
XOR_op ENDP
END main
```

**테이블 기반 선택의 구조** ⭐
- 각 항목은 **(비교값 1바이트) + (프로시저 주소 4바이트)** = 5바이트
- `EntrySize`를 어셈블러가 계산하게 하면 유지보수가 쉽습니다
- `call NEAR PTR [ebx+1]` — 간접 호출. **NEAR PTR이 필요**합니다
- 조건이 많아질수록 CMP/JMP 나열보다 유리합니다

### 8. XOR 메시지 암호화 ★★

**문제**: 6.3.4절의 암호화 프로그램을 확장하시오. 한 글자가 아닌 **여러 글자로 된 키**를 쓰고, 키를 반복하며 평문의 각 바이트와 XOR 합니다.

```asm
INCLUDE Irvine32.inc

KEY_SIZE = 7
BUF_MAX  = 128

.data
key        BYTE "ABXmv#7"              ; 7글자 키
buffer     BYTE BUF_MAX+1 DUP(0)
bufSize    DWORD ?

promptMsg  BYTE "Enter plain text: ",0
encMsg     BYTE 0dh,0ah,"Cipher text: ",0
decMsg     BYTE 0dh,0ah,"Decrypted:   ",0

.code
main PROC
    call InputTheString
    call TranslateBuffer

    mov edx,OFFSET encMsg
    call DisplayMessage

    call TranslateBuffer        ; 한 번 더 하면 복호화

    mov edx,OFFSET decMsg
    call DisplayMessage

    call Crlf
    exit
main ENDP

;---------------------------------------------------
InputTheString PROC USES ecx edx
    mov edx,OFFSET promptMsg
    call WriteString
    mov ecx,BUF_MAX
    mov edx,OFFSET buffer
    call ReadString
    mov bufSize,eax             ; 실제 입력 길이
    ret
InputTheString ENDP

;---------------------------------------------------
; TranslateBuffer
; 버퍼를 다중 문자 키로 XOR 한다.
;---------------------------------------------------
TranslateBuffer PROC USES eax ecx esi edi
    mov ecx,bufSize
    cmp ecx,0
    je  done

    mov esi,0                   ; 버퍼 인덱스
    mov edi,0                   ; 키 인덱스

L1:
    mov al,key[edi]             ; 현재 키 문자
    xor buffer[esi],al          ; 평문과 XOR

    inc esi                     ; 다음 평문 문자

    inc edi                     ; 다음 키 문자
    cmp edi,KEY_SIZE
    jb  L2                      ; 키 끝에 도달하지 않았으면
    mov edi,0                   ; 키를 처음으로 되돌림

L2:
    loop L1

done:
    ret
TranslateBuffer ENDP

;---------------------------------------------------
DisplayMessage PROC USES edx
    call WriteString            ; EDX의 레이블 표시
    mov edx,OFFSET buffer
    call WriteString            ; 버퍼 내용 표시
    ret
DisplayMessage ENDP
END main
```

**핵심** ⭐
- **인덱스 두 개**를 따로 관리합니다. ESI는 평문, EDI는 키입니다.
- 키 인덱스가 끝에 닿으면 **0으로 되돌립니다**. 이것이 키 반복의 핵심입니다.
- XOR의 가역성 덕분에 **같은 함수를 두 번 부르면 원문으로 돌아옵니다**.

**동작 예시**

| 위치 | 0 | 1 | 2 | ... | 7 | 8 |
|---|---|---|---|---|---|---|
| 평문 | T | h | i | ... | s | a |
| 키 | A | B | X | ... | **A** | **B** |

키가 7글자이므로 8번째 평문 문자부터 키가 다시 처음으로 돌아갑니다.

### 9. 소수 찾기 (에라토스테네스의 체) ★★★

**문제**: 2부터 1000까지의 소수를 모두 찾아 표시하시오. 배열은 초기화되지 않은 데이터 세그먼트에 선언하고 STOSB로 0을 채웁니다.

```asm

MAX_NUM = 1000

.data?
sieve BYTE MAX_NUM DUP(?)       ; 미초기화 영역

.data
msg BYTE "Prime numbers from 2 to 1000:",0dh,0ah,0

.code
main PROC
    call Clrscr
    mov edx,OFFSET msg
    call WriteString

    call InitSieve
    call MarkComposites
    call ShowPrimes

    call Crlf
    exit
main ENDP

;---------------------------------------------------
; InitSieve
; 배열을 모두 0으로 채운다 (0 = 소수 후보)
;---------------------------------------------------
InitSieve PROC USES eax ecx edi
    mov edi,OFFSET sieve
    mov ecx,MAX_NUM
    mov al,0
    cld                         ; 방향 플래그: 전진
    rep stosb                   ; AL을 ECX번 저장
    ret
InitSieve ENDP

;---------------------------------------------------
; MarkComposites
; 합성수 위치를 1로 표시한다.
;---------------------------------------------------
MarkComposites PROC USES eax ebx ecx
    mov ebx,2                   ; 현재 소수 후보

outerLoop:
    ; ebx * ebx > MAX_NUM 이면 종료
    mov eax,ebx
    mul ebx                     ; EAX = ebx^2
    cmp eax,MAX_NUM
    jae done

    ; sieve[ebx]가 0이면 소수
    cmp sieve[ebx],0
    jne nextCandidate           ; 이미 표시됨 → 건너뜀

    ; ebx의 배수들을 표시
    mov eax,ebx
    add eax,ebx                 ; 2*ebx 부터 시작

innerLoop:
    cmp eax,MAX_NUM
    jae nextCandidate
    mov sieve[eax],1            ; 합성수 표시
    add eax,ebx                 ; 다음 배수
    jmp innerLoop

nextCandidate:
    inc ebx
    jmp outerLoop

done:
    ret
MarkComposites ENDP

;---------------------------------------------------
; ShowPrimes
; 표시되지 않은(0인) 위치의 숫자를 출력한다.
;---------------------------------------------------
ShowPrimes PROC USES eax ebx ecx
    mov ebx,2                   ; 2부터 시작
    mov ecx,0                   ; 줄바꿈용 카운터

L1:
    cmp ebx,MAX_NUM
    jae done

    cmp sieve[ebx],0
    jne skip                    ; 합성수면 건너뜀

    mov eax,ebx
    call WriteDec
    mov al,' '
    call WriteChar

    inc ecx
    cmp ecx,10                  ; 10개마다 줄바꿈
    jb  skip
    call Crlf
    mov ecx,0

skip:
    inc ebx
    jmp L1

done:
    ret
ShowPrimes ENDP
END main
```

**알고리즘 설명** ⭐

1. 배열을 모두 0으로 초기화합니다 (0 = 아직 소수 후보)
2. 2부터 시작해 각 수에 대해
   - 이미 표시되었으면(합성수) 건너뜁니다
   - 표시되지 않았으면 소수이므로, 그 **배수들을 모두 1로 표시**합니다
3. 끝까지 0으로 남은 위치가 소수입니다

**최적화 포인트**
- 바깥 루프는 `ebx² > MAX_NUM` 이면 멈춰도 됩니다. 그보다 큰 수의 배수는 이미 작은 소수가 표시했기 때문입니다.
- 내부 루프를 `ebx*ebx` 부터 시작하면 더 빠릅니다.

**STOSB 사용**
```asm
mov edi,OFFSET sieve    ; 대상 주소는 EDI
mov ecx,MAX_NUM         ; 반복 횟수
mov al,0                ; 저장할 값
cld                     ; 방향 = 전진
rep stosb               ; AL을 [EDI]에 저장하고 EDI 증가, ECX번 반복
```
> 9장에서 자세히 배우지만, 배열을 특정 값으로 채울 때 루프보다 빠릅니다.

### 10. 버블 정렬 개선 ★

**문제**: 6장 범위를 넘지만, 교환 플래그를 두어 한 번의 패스에서 교환이 없으면 정렬을 조기 종료하시오.

```asm
;---------------------------------------------------
; BubbleSort (개선판)
; Receives: ESI = 배열 주소, ECX = 원소 개수
;---------------------------------------------------
BubbleSort PROC USES eax ebx ecx esi
    mov ecx,count
    dec ecx                     ; 바깥 루프 횟수

outerLoop:
    push ecx
    mov esi,OFFSET array
    mov bl,0                    ; 교환 플래그 초기화

innerLoop:
    mov eax,[esi]
    cmp eax,[esi+4]
    jle noSwap                  ; 순서가 맞으면 교환 안 함

    xchg eax,[esi+4]
    mov [esi],eax
    mov bl,1                    ; 교환 발생 표시

noSwap:
    add esi,4
    loop innerLoop

    pop ecx
    cmp bl,0                    ; 이번 패스에 교환이 있었나?
    je  sorted                  ; 없으면 이미 정렬됨 → 종료
    loop outerLoop

sorted:
    ret
BubbleSort ENDP
```

**개선 효과**
- 이미 정렬된 배열이면 **한 번의 패스**만에 끝납니다.
- 최악의 경우는 동일하지만 평균 성능이 좋아집니다.
- BL을 플래그로 쓰는 것이 핵심입니다.

# 6장 시험 대비 요점

## 비트 연산 용도 암기

| 목적 | 명령어 | 마스크 |
|---|---|---|
| 특정 비트 **지우기** | AND | 지울 자리 **0**, 남길 자리 1 |
| 특정 비트 **세우기** | OR | 세울 자리 **1**, 나머지 0 |
| 특정 비트 **반전** | XOR | 반전할 자리 **1**, 나머지 0 |
| 비트 **검사** (값 유지) | TEST | 검사할 자리 1 |
| 전체 반전 | NOT | — |
| 레지스터 **0으로** | XOR reg,reg | — |

⭐ **AND·OR·XOR·TEST는 CF와 OF를 0으로 지웁니다. NOT은 플래그를 안 바꿉니다.**

## 조건 점프 선택 ⭐⭐⭐

```
A / B  (Above / Below)   →  부호 없는 (unsigned)
G / L  (Greater / Less)  →  부호 있는 (signed)
```

| 관계 | 부호 없음 | 부호 있음 |
|---|---|---|
| > | JA | JG |
| ≥ | JAE | JGE |
| < | JB | JL |
| ≤ | JBE | JLE |
| = | JE | JE |
| ≠ | JNE | JNE |

## CMP 후 플래그

| 비교 | 부호 없음 | 부호 있음 |
|---|---|---|
| 좌 < 우 | CF = 1 | SF ≠ OF |
| 좌 = 우 | ZF = 1 | ZF = 1 |
| 좌 > 우 | CF=0, ZF=0 | SF = OF, ZF = 0 |

## 조건문 변환 공식 ⭐⭐

**단순 IF** — 조건을 뒤집어 건너뛰기
```asm
cmp a,b
jne skip        ; (a == b 를 구현할 때)
    ; then 블록
skip:
```

**IF-ELSE**
```asm
cmp a,b
jle elsePart
    ; then
    jmp endIf
elsePart:
    ; else
endIf:
```

**AND 복합조건** — 각 조건을 뒤집어 거짓일 때 탈출
```asm
cmp a,b
jbe skipAll     ; 첫 조건 실패
cmp c,d
jbe skipAll     ; 둘째 조건 실패
    ; 둘 다 참
skipAll:
```

**OR 복합조건** — 참이면 실행부로, 마지막만 뒤집기
```asm
cmp a,b
ja  doIt        ; 첫 조건 참
cmp c,d
jbe skipAll     ; 둘째도 거짓
doIt:
    ; 하나라도 참
skipAll:
```

**WHILE 루프**
```asm
whileTop:
    cmp a,b
    jge whileEnd    ; 조건이 거짓이면 탈출
    ; 본문
    jmp whileTop
whileEnd:
```

## 조건 루프 명령어

| 명령어 | 반복 조건 |
|---|---|
| LOOPZ / LOOPE | ECX > 0 **그리고** ZF = 1 |
| LOOPNZ / LOOPNE | ECX > 0 **그리고** ZF = 0 |

⭐ **ECX를 먼저 감소**시킨 뒤 조건을 봅니다. 이 명령어들은 플래그를 바꾸지 않습니다.

## 자주 나오는 함정

- **같은 데이터라도 A/B와 G/L의 결과가 다릅니다** (문제 14, 16번 참고)
- 64비트에서 **32비트 상수를 AND 하면 상위 32비트가 유지**됩니다 (문제 19번)
- TEST는 결과를 저장하지 않고 플래그만 바꿉니다
- 학점 판정 같은 다단계 비교는 **높은 쪽부터** 검사합니다
- `.IF` 로 레지스터끼리 비교하면 **부호 없는 비교**가 됩니다
- 테이블 기반 호출에는 **NEAR PTR** 이 필요합니다
