
발표 제목
AI 시대, RAM은 사라질 수 있을까?
— SRAM, L3 Cache, HBM 그리고 통합 메모리의 미래

1. 문제 제기 — 왜 AI는 메모리를 많이 필요로 할까?
AI 모델은 수십억~수조 개의 파라미터를 가짐
연산 성능이 높아져도 데이터를 가져오는 속도가 느리면 성능이 제한됨
AI 시대에는 연산 성능뿐 아니라 메모리 대역폭과 데이터 이동이 중요해짐
핵심 질문

“RAM을 더 빠르게 만드는 대신, 아예 RAM에 접근할 필요를 줄이면 어떨까?”

2. 컴퓨터의 메모리 계층
빠름 ↑
│
│   L1 Cache      ← 매우 작음 / 매우 빠름
│   L2 Cache
│   L3 Cache
│   HBM
│   DRAM (RAM)
│   SSD           ← 매우 큼 / 느림
│
└──────────────→ 용량

핵심 원칙

빠를수록 비싸고 작으며, 느릴수록 싸고 크다.

3. 왜 캐시를 무작정 크게 만들지 않을까?
L1/L2/L3 캐시는 주로 SRAM으로 구성됨.

SRAM:

매우 빠름
낮은 지연시간
하지만 높은 집적 비용
많은 칩 면적 필요
대용량화할수록 가격 상승
따라서

“RAM을 SRAM으로 전부 대체하자”

는 기술적으로 가능하더라도 경제성이 떨어짐.

4. 그렇다면 캐시 중 어디를 키우는 게 유리할까?
CPU Core
   │
   ▼
 L1  → 속도가 최우선
   │
   ▼
 L2  → 속도 + 용량
   │
   ▼
 L3  → 용량 확대에 상대적으로 유리
   │
   ▼
 RAM

L3 캐시는 여러 코어가 공유하며 RAM 접근을 줄이는 역할

따라서 SRAM을 추가한다면

L1을 무작정 키우기보다는 L3를 키우는 것이 현실적인 방향

5. 실제 사례 — AMD 3D V-Cache
AMD는 3D V-Cache 기술을 통해 L3 캐시를 수직으로 적층.

기존:

CPU
└── L3 Cache

3D V-Cache:

       CPU
        │
   ┌────▼────┐
   │ 기본 L3 │
   ├─────────┤
   │ 추가 L3 │
   └─────────┘

핵심 아이디어

옆으로 칩을 키우는 대신 위로 SRAM을 쌓는다.

→ 같은 CPU 면적에서 더 큰 캐시 확보

6. 그런데 L3를 1GB, 4GB로 계속 키우면?
이론적으로는:

L3
32MB
 ↓
64MB
 ↓
256MB
 ↓
1GB
 ↓
4GB

처럼 계속 키울 수 있음.

하지만 문제가 발생함.

칩 면적
비용
전력 소비
발열
제조 수율
캐시 접근 지연 증가
그리고 가장 중요한 문제:

캐시가 커진 만큼 성능이 비례해서 증가하지 않는다.

7. 그래서 등장하는 현실적인 타협 — HBM
HBM은 DRAM 기반이지만 GPU/가속기에 매우 가까이 배치하고 매우 넓은 인터페이스를 사용함.

       GPU
        │
   ═════╪═════
        │
      HBM
   ███████████
   ███████████

SRAM:

작지만 극도로 빠름

HBM:

훨씬 크면서 엄청난 대역폭

따라서 AI에서는 SRAM과 DRAM 사이의 중요한 역할을 담당.

8. 또 다른 방향 — 통합 메모리
Apple의 Apple Silicon은 CPU/GPU/NPU 등이 하나의 통합 메모리 풀을 공유하는 구조를 사용.

       ┌─────────┐
       │   CPU   │
       ├─────────┤
       │   GPU   │
       ├─────────┤
       │   NPU   │
       └────┬────┘
            │
     ┌──────▼──────┐
     │ 통합 메모리 │
     └─────────────┘

장점:

CPU ↔ GPU 데이터 복사 감소
메모리 활용 효율 증가
AI 작업에 유리
시스템 구조 단순화 가능
9. 미래의 모습
현재:

CPU → Cache → RAM → SSD
GPU → VRAM → SSD

미래:

           CPU
            │
      GPU ──┼── NPU
            │
      초고속 메모리
            │
       대용량 메모리
            │
           SSD

메모리의 경계가 점점 흐려질 가능성.

특히:

3D 적층
HBM
통합 메모리
새로운 비휘발성 메모리
Processing-in-Memory
등이 발전하면서 “RAM이라는 별도의 부품”의 중요성이 감소할 수 있음.

10. 결론 — RAM은 정말 사라질까?
완전히 사라진다고 단정하기는 어렵다.

하지만

RAM이라는 독립적인 계층이 지금과 같은 형태로 존재할 필요는 점점 줄어들 수 있다.

미래의 핵심은:

“얼마나 많은 RAM을 가지고 있는가?”

에서

“데이터를 연산 장치까지 얼마나 빠르고 적은 비용으로 이동시키는가?”

로 이동할 가능성이 높다.

한 문장으로 정리
AI 시대의 메모리 혁신은 RAM을 더 크게 만드는 것이 아니라, RAM에 접근해야 하는 횟수 자체를 줄이는 방향으로 발전하고 있다.
